# 电池 OEM 网站 页面类型规划 v2（含流量支柱/细分分层）

> 三原则：**转化最大化**（ToB 询盘页）+ **流量最大化**（支柱页聚权 + 细分页收割长尾）+ **主题簇闭环**（Pillar 权重 → Cluster 长尾 → 转化页收口）

## 〇、架构总览：三层漏斗

```
【流量支柱页 Pillar】—— 大词/主题入口，聚权重，内链导向细分
      │ 内链(权重传导)         ▲ 内链(长尾回流)
      ▼                        │
【流量细分页 Cluster】—— 型号/品牌/场景长尾，收割精确流量
      │ 转化引导
      ▼
【转化页】—— OEM/认证/PACK/批发，询盘收口
```

> 权重流：博客 → 支柱页 ← 细分页 → 转化页。**支柱页是内链枢纽**——每个细分页都必须从支柱页获得入链，并回链支柱。

## 六、规划要点（为什么支柱页要先做）

1. **支柱页 = 权重枢纽**：所有细分页的入链从支柱页出，权重集中不分散
2. **细分页 = 长尾金矿**：cr2032 90.5K 单个型号就超过 aa battery 支柱——细分页不细，是流量主体
3. **转化页 = 收口**：每个支柱/细分页的 CTA 指向转化页，询盘闭环
4. **先做支柱后做细分**：支柱页上线即确定 URL 结构，细分页照模板批量生成
5. **型号页是特殊细分**：它们既是细分（从纽扣支柱拿权重），又是小支柱（各自聚合型号词）——双向链接
