# 电池 OEM 网站 — 技术 SEO 规范

> 建站时必须遵守的技术规范。含：URL 地图 / Title 格式 / Schema 代码 / 图片规范 / sitemap。

## 1. URL 结构规范

| 页面类型 | URL 模式 | 示例 |
|---|---|---|
| 首页 | / | / |
| 产品线页 | /{产品}-battery/ | /aa-battery/ /d-battery/ |
| 场景页 | /{场景}-battery/ | /watch-battery/ /key-fob-battery/ |
| 型号页 | /battery-type/{型号}-battery/ | /battery-type/cr2032-battery/ |
| 车型子页 | /key-fob-battery/{品牌}/ | /key-fob-battery/nissan/ |
| 品牌子页 | /watch-battery/{品牌}/ | /watch-battery/apple/ |
| 转化页 | 短语义 slug | /oem-battery-manufacturing/ /battery-pack/ |
| 博客 | /blog/{slug}/ | /blog/aa-vs-aaa-battery/ |

**规则**：
- 全部小写 + 连字符（-），禁止下划线/空格/中文
- 型号页统一 `/battery-type/{型号}-battery/`（377 → 377-battery）
- URL 不含日期/参数（博客除外可带 slug）
- 一个页面一个 URL，禁止重复内容

## 2. Title / Meta Description 格式

### Title 公式（60 字符内）

`{主关键词} | {差异化卖点} | {品牌}`

| 页面类型 | Title 模板 |
|---|---|
| 型号页 | {型号} Battery - {规格} {化学} | OEM Manufacturer |
| 产品线页 | {AA/AAA/D} Batteries - {特性} | Bulk & OEM Supply |
| 场景页 | {场景} Battery Replacement - Find Your {型号} |
| OEM 页 | Battery OEM/ODM Manufacturing - Custom Design to Packaging |
| 认证页 | Battery Certifications - UL, UN38.3, IEC, CE |
| 批发页 | Wholesale Batteries - Bulk {AA/AAA} | China Factory Direct |
| 博客 | {主题} - Battery Guide |

### Meta Description 公式（155 字符内）

`{主关键词} {规格/数据} - {1句价值} {CTA词}。`

⚠️ **复数铁律**：电池词 Title/H1/正文用复数（aa batteries 非 aa battery）——美国搜索习惯

## 3. Schema 结构化数据（JSON-LD）

### 3.1 Product Schema（型号页/产品线页）

```json
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": "CR2032 Battery",
  "description": "3V lithium coin cell, 20mm x 3.2mm, 220mAh. Compatible with 5004LC/ECR2032/DL2032.",
  "brand": {"@type": "Brand", "name": "{品牌}"},
  "offers": {"@type": "AggregateOffer", "priceCurrency": "USD", "availability": "https://schema.org/InStock"}
}
```

### 3.2 FAQPage Schema（全站 FAQ 区块）

```json
{
  "@context": "https://schema.org/",
  "@type": "FAQPage",
  "mainEntity": [
    {"@type": "Question", "name": "What is a CR2032 battery?", "acceptedAnswer": {"@type": "Answer", "text": "20mm lithium coin cell, 3V, ~220mAh."}},
    {"@type": "Question", "name": "Is CR2032 rechargeable?", "acceptedAnswer": {"@type": "Answer", "text": "No, standard CR2032 is primary lithium."}}
  ]
}
```

### 3.3 BreadcrumbList（全站面包屑）

```json
{
  "@context": "https://schema.org/",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {"@type": "ListItem", "position": 1, "name": "Home", "item": "https://{域名}/"},
    {"@type": "ListItem", "position": 2, "name": "Button Cell Batteries", "item": "https://{域名}/button-cell-battery/"},
    {"@type": "ListItem", "position": 3, "name": "CR2032", "item": "https://{域名}/battery-type/cr2032-battery/"}
  ]
}
```

### 3.4 Organization（全站首页/页脚）

```json
{
  "@context": "https://schema.org/",
  "@type": "Organization",
  "name": "{品牌}",
  "url": "https://{域名}/",
  "description": "Battery OEM manufacturer - custom AA, AAA, button cell & battery pack",
  "contactPoint": {"@type": "ContactPoint", "contactType": "sales"}
}
```

## 4. 图片规范

| 项 | 规范 |
|---|---|
| 命名 | {型号}-battery.jpg / aa-battery-alkaline.jpg（关键词命名） |
| 格式 | WebP 优先（压缩），PNG 用于透明图 |
| 尺寸 | Hero 1200px+，产品图 800px，缩略图 300px |
| alt 文本 | 用关键词：'CR2032 battery 3V lithium coin cell' |
| 懒加载 | loading="lazy"（首屏除外） |
| 尺寸属性 | width/height 固定防 CLS |

## 5. 技术配置

| 项 | 配置 |
|---|---|
| HTTPS | 强制跳转，HSTS |
| 域名规范 | www 与非 www 二选一 301 |
| sitemap.xml | 全站页面（57 + 后续博客），首页引用 |
| robots.txt | 允许全部，sitemap 指向 |
| 404 页 | 自定义 + 返回首页链接 |
| 页面速度 | 目标 LCP<2.5s，图片 WebP 压缩 |
| 移动端 | 响应式优先（Google 移动优先索引） |
| 分析 | GA4 + GSC（Search Console） |
| hreflang | 暂不启用（4.2 决策） |
