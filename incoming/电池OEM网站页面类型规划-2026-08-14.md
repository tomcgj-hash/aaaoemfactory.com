# 电池 OEM 网站 页面类型规划（转化最大化 × 流量最大化）

> 原则：**转化最大化 = 高意图 ToB 词做询盘页（利润核心）；流量最大化 = 大搜索量/长尾词做流量页（权重基本盘）**。两种页面通过内链闭环：流量页 → 型号页 → 转化页。

## 二、流量→转化 闭环设计

```
博客页(学习意图) ──内链──▶ 场景页(替换意图) ──▶ 型号页(精确词) ──▶ 服务/批发页(询盘)
  流量漏斗顶          转化意图增强          精准承接            询盘收口
```

## 1. 服务能力页（转化最大化）

- **目的**: 承接『找工厂定制/采购』的高意图 ToB 询盘——网站利润核心
- **关键词特征**: battery oem/odm/custom/manufacturer/supplier 等采购意图词，CPC $0.8-3.56，量小但询盘价值高
- **对应词根**: battery oem (807K量) / battery odm / custom battery / battery manufacturer / battery supplier / battery factory
- **页数**: 5
- **结构要点**: 定制流程4步 + 能力清单（电压/容量/尺寸/标签）+ 认证墙 + 案例 + MOQ/交期表 + 询盘表单
- **CTA**: 『Start Your Custom Project』『Get Quote』
- **优先级**: P0
- **页面清单**: OEM/ODM定制页, 认证页, 电池组PACK页, 批发页, 首页(制造商承接)

## 2. 询盘转化页（转化最大化）

- **目的**: 把流量页进来的访客转化为询盘——每个产品页的转化收口
- **关键词特征**: 产品词+采购修饰（bulk/price/wholesale/oem），下拉词采购意图 910 个
- **对应词根**: aa battery bulk / aa battery price / wholesale aa batteries / private label battery
- **页数**: 随产品页
- **结构要点**: 产品规格表 + OEM 定制 CTA + 批发 CTA + 询盘表单 + 交期/起订量
- **CTA**: 『Get Bulk Price』『Customize』
- **优先级**: P0
- **页面清单**: 每个产品线页内嵌转化区块

## 3. 产品线流量页（流量最大化）

- **目的**: 吃大搜索量产品词——养全站权重，是流量基本盘
- **关键词特征**: aa/aaa/d/button cell/rechargeable 大词，单词 12-33K 月量
- **对应词根**: aa battery 18.1K / aa batteries 33.1K / aaa 12.1K / d battery 27.1K / button cell 2.4K
- **页数**: 6
- **结构要点**: Hero+规格表+化学体系子块+应用场景+FAQ+内链到型号页/转化页
- **CTA**: 双 CTA（批发+OEM），页尾询盘
- **优先级**: P1
- **页面清单**: AA电池页, AAA电池页, D电池页, 纽扣电池总页, 可充电页, USB可充电页

## 4. 场景流量页（流量最大化）

- **目的**: 吃设备场景词（换电池意图）——量大且购买意图明确
- **关键词特征**: watch/key fob/cmos battery，replacement/change 修饰占主导
- **对应词根**: watch battery 9.9K (replacement 355K) / key fob 18.1K (replacement 484K) / cmos 12.1K
- **页数**: 3
- **结构要点**: 替换指南 + 该设备用哪些型号 + 型号对照 + 购买CTA（流量→转化）
- **CTA**: 『Find Your Battery Size』→ 型号页 → 询盘
- **优先级**: P1
- **页面清单**: 手表电池页, 车钥匙电池页, CMOS电池页

## 5. 型号长尾页（流量最大化）

- **目的**: 吃型号精确词——量大（CR2032 90.5K）、竞争低、长尾金矿
- **关键词特征**: cr2032/lr44/ag13 等型号词，兼容对照词（equivalent/cross reference）
- **对应词根**: cr2032 90.5K / lr44 74K / cr2025 22.2K / cr2450 22.2K / ag13 18.1K / lr41 14.8K
- **页数**: 12
- **结构要点**: 规格表 + 兼容对照（LR44=AG13=357）+ 应用 + FAQ + 相关型号互链（模板化）
- **CTA**: 『Buy CR2032 in Bulk』『Customize』
- **优先级**: P1
- **页面清单**: 12 个型号页（统一模板）

## 6. 场景子页（品牌×型号）（流量最大化）

- **目的**: 吃『品牌设备+电池』精确长尾——量巨大且购买意图极强
- **关键词特征**: nissan key fob battery / apple watch battery / dell cmos battery，品牌词+场景词组合
- **对应词根**: key fob: nissan 136K/honda 131K/toyota 91K/ford 83K... watch: apple 280K/fossil 31K... cmos: dell 11K/hp 6K
- **页数**: 18
- **结构要点**: 品牌设备型号速查 + 换电池步骤 + 型号对照 + 购买CTA（模板化）
- **CTA**: 『Get the Right Battery』→ 型号页 → 询盘
- **优先级**: P2
- **页面清单**: 车钥匙车型页10, 手表品牌页5, CMOS品牌页3

## 7. 内容/博客页（流量最大化）

- **目的**: 收割学习/问答意图长尾（541 词）——养权重、进用户漏斗顶
- **关键词特征**: how long/can you/how to/replace 开头问答词，how many volts is aa battery 1.3K
- **对应词根**: 学习意图下拉词 541 个（如何/能否/寿命/区别/更换/回收）
- **页数**: 10
- **结构要点**: 指南/教程/对比/FAQ 内容 + 内链到产品页/型号页（流量→转化）
- **CTA**: 正文内链 + 尾部产品推荐
- **优先级**: P3
- **页面清单**: 10 篇指南（寿命/更换/携带/回收/对比）

## 四、转化页 vs 流量页 关键区别

| 维度 | 转化最大化页 | 流量最大化页 |
|---|---|---|
| 目标 | 询盘/订单 | 搜索流量/排名 |
| 关键词 | ToB 采购词（量小价高） | 产品/场景/型号词（量大） |
| CTA | 询盘表单为主 | 内链+型号引导为主 |
| 内容 | 能力/案例/认证/流程 | 规格/指南/FAQ/对照 |
| 内链方向 | 收口到询盘 | 传递到转化页 |
| 衡量 | 询盘量/转化率 | 流量/排名/点击 |
