## 3. 技术 SEO 规范（必须遵守）

| 项 | 规范 |
|---|---|
| URL 格式 | 小写连字符 slug，型号页 /battery-type/{型号}-battery/ |
| 关键词复数 | 电池词美国用复数：Title/H1 用 aa batteries 非 aa battery |
| 标题格式 | {主关键词} | {差异化} | {品牌}（OEM 工厂定位） |
| Schema | 型号页/产品页用 Product Schema；FAQ 用 FAQPage；全站 BreadcrumbList |
| 内链 | 按《内链锚文本+FAQ库》：70% 关键词锚，每页面包屑，OEM 页全站必链 |
| 图片 | alt 用关键词，命名 {型号}-battery.jpg，压缩 WebP |
| hreflang | 暂不做多语言（4.2 决策方案C） |

## 5. 数据口径（防止误读）

| 概念 | 含义 |
|---|---|
| by_count | 词根关键词数量（内容机会），**不是搜索量** |
| by_volume | 词根聚合搜索量（流量机会），次/月 |
| 搜索量 | 美国月搜索量（Semrush 实测） |
| KD | 关键词难度（%），不可用=Semrush 无数据 |
| 下拉词 | Google/Bing 真实用户联想，反映搜索习惯 |
